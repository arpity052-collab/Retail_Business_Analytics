# Retail Business Analytics

## Project Overview

Retail Business Analytics is a data analytics project designed to analyze retail sales, customer behavior, product performance, profitability, and order trends.

The project uses data analysis and visualization techniques to transform raw retail data into meaningful business insights that can support better decision-making.

## Business Problem

Retail businesses generate large amounts of customer, sales, product, and order data. Analyzing this data manually can make it difficult to identify profitable products, customer trends, sales patterns, and business performance.

This project provides an analytical approach to understand these patterns and support data-driven business decisions.

## Objectives

- Analyze retail sales and revenue trends
- Understand customer demographics and behavior
- Identify high-performing products
- Analyze profit and cost
- Study order status and payment methods
- Compare business performance across regions and locations
- Generate meaningful insights using data visualization

## Dataset

The project uses a synthetic retail business dataset containing customer, product, sales, cost, profit, payment, order, and location-related information.

### Dataset Size

- Records: 50,000
- Final analytical columns: 23
